# Tasks

This project's tasks are tracked in the app itself, not in this file.

- **Data:** `data/todo.txt` and `data/done.txt`, in the repo root and gitignored.
- **Run it:** `PORT=3002 node server.js`, then open http://localhost:3002. Pick any free port.
- **Format and agent rules:** `docs/FORMAT.md`. Run `node validate.js data` after any edit to the files.
- **History:** the build plan that lived here (Phases 1 to 12, 62 items) was imported into the app as one `+TaskFlow` project, one root task per phase. The previous text is in git: `git log -p -- docs/TASKS.md`.
